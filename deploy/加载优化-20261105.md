## 改动与结果

- 运行图片转换为 42 张 WebP，合计 708,418 字节；其余预览、整页参考、示例、重复部件及原始素材包元数据从公开目录移除。用户原始 ZIP 和 Git 历史可追溯来源。
- 2.07 MB 透明图集改为五张实际部件；首页只下载 46 KB 的标志部件。
- 2.43 MB 背景转换为 192 KB WebP，另有 74 KB 窄屏背景。手机实测只请求一张 960 像素背景，未重复下载预加载图片。
- 内容哈希图片使用一年不可变缓存；脚本、样式使用 ETag/304 和 gzip。HTML 与游戏接口仍不缓存，实时事件流行为保持不变。
- 42 张线上图片均通过 HTTP 状态、WebP 类型、不可变缓存和内容哈希检查；旧整张图集返回 404，脚本 gzip 和 304 均在公网验证。
- 36 项自动化在 Node 20/22 CI 和腾讯云 Node 24 均通过。8 种窗口尺寸的规则布局检查、公网六种视口回归与三会话完整对局通过，共抽牌 12 次，无页面异常。
- 浏览器回归最初用轮询等待短暂的翻牌展示，公网条件下会漏采；现提前注册 MutationObserver，逐端记录真正出现的展示节点、牌面与可见区域。未改变运行时的翻牌时长或游戏逻辑。
