# 参考图场景素材

本目录用于 2026-11-05 的视觉构图校准。

- room-scene.png：用户提供的无字完整房间底图，原样复制，1672×941。它不含游戏按钮、房间号或玩家状态，只作为背景。
- ui-atlas.png：用户提供的透明组件图，原样复制，1448×1086；由 atlasRegions 中的坐标窗口显示对应部件，没有重新抠图或拆写原图。
- seated-girl.png / seated-boy.png：原素材中缺少的坐姿人物层，使用内置 image_gen 按等待房间参考图补齐，保留透明背景；网页版本为 720×480 PNG。最终提示词和来源记录在 provenance.json。

## 运行布局

等待房间以 1672×941 的参考坐标绘制，按窗口缩放保持牌匾和按钮的比例；窄屏竖屏单独布局，多人时优先保留成员与操作区。超出两个主座位的成员用紧凑头像显示。空位不显示信息框。

等待状态呈现围桌人物；开局保留相同玩家与身份，转为以自己手牌为中心的对局头像布局。背景节点不重新创建，视角可收近。

房间号、昵称、身份、按钮文字仍是 HTML。每张真实扑克牌保持独立 DOM，通过服务端动作播放选中、翻牌、移牌和配对动画。这里没有把带有固定状态的完整效果图当作游戏界面。
