# 龟牌派对 · Turtle Party

**抽乌龟（Old Maid）多人网页纸牌游戏** · 当前版本 **v0.4.0** · [English](README.en.md)

支持 **2～6 人**、AI 对战与好友房间。采用原生 HTML / CSS / JavaScript、Node.js 和 SSE；**无需数据库、Docker 或第三方 npm 依赖**。

> **验证范围：** 已有自动化、桌面及模拟手机浏览器验证；实体 Android / iOS 手机、真实网络切换和高并发安全压测仍未完成。线上地址：[cwg.duanap.cn](https://cwg.duanap.cn)。

## 核心功能

- **快速开始：** 默认 1 名真人 + 3 名 AI。
- **好友联机：** 创建或加入 2～6 人房间，六位纯数字房间号，房主可以补充 AI。
- **经典玩法：** 从 52 张牌中随机移除 1 张，同点数自动配对，最后持有单张的人失败。
- **操作体验：** 选牌同步提起、全桌翻牌、入手后配对消除；支持洗序、PC 拖牌和手机长按排序。界面全中文，首页规则常显。
- **网络恢复：** SSE 状态推送、弱网轮询、短暂断线托管、会话恢复和单机 JSON 快照。

## 快速运行

要求 **Node.js 20 或更高版本**，无需执行 `npm install`：

```bash
npm start
# 浏览器访问 http://127.0.0.1:3000

npm test
```

默认只监听本机 `127.0.0.1:3000`。可信局域网测试可使用 `HOST=0.0.0.0 PORT=3000 npm start`；**公网不要直接开放 3000 端口**，请通过 HTTPS 反向代理访问。

## 开发与限制

执行 `npm test` 运行 **28 项**自动化测试；GitHub Actions 同时验证 Node.js 20 和 22。提交变更欢迎使用 Issue / Pull Request。

单实例内存房间使用私有 `data/rooms.json` 快照；**不得启动多个进程共享同一个数据文件**，亦不要将 `data/` 上传到仓库。浏览器本地保留会话凭证以支持断线恢复，应当使用 HTTPS。

**许可证：** 仓库目前未声明开源许可证；公开可访问不代表自动授予复制、修改或再分发许可。
