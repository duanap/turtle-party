# 测试、验收与已知限制

**适用版本：** 0.4.0 沉浸式牌桌迭代。本分支以 PR 审查为交付范围；模拟浏览器验证不等同于实体手机验收。

## 原生自动化

```bash
npm test
```

当前 **33 项测试**，涵盖：

- 发牌、配对、合法抽牌、特殊残局及公平电脑。
- 房间身份、选牌同步、公开翻牌、幂等、断线托管与重启。
- 房间号前导零、碰撞重试和达到上限时拒绝。
- 快照、旧房间兼容、预览清除、损坏数据和 Linux 文件权限。
- 中文界面、常显规则、表单与被抽者提牌。

GitHub Actions 使用 Node 20、22，结果以对应提交的检查为准。Windows 不具备相同的 POSIX 权限语义，0600 断言在 Linux 执行。

## 可复现浏览器验收

游戏服务启动后，在提供 Playwright 的开发环境执行：

```bash
npm start
# 另一个终端
npm run test:browser
```

浏览器工具不属于游戏运行依赖。可选配置：

| 环境变量 | 用途 |
| --- | --- |
| PLAYWRIGHT_MODULE | 工具中 Playwright 的模块路径，省略时标准解析 |
| BROWSER_CHANNEL | 可选 chrome、msedge；省略时使用安装的默认 Chromium |
| BROWSER_BASE_URL | 默认 http://127.0.0.1:3000 |
| BROWSER_OUTPUT_DIR | 截图及 JSON 报告目录，默认系统临时目录中的 turtle-party-browser |

脚本通过真实表单和 HTTP/SSE 驱动，覆盖：

- 1440×900、1280×720、844×390、740×360、667×375、390×844 六种视口。
- 表单单行、五条常显规则、中文非法输入提示、背景节点保留。
- 弹窗退出键、焦点循环、音效与减少动态效果设置持久化。
- 二至六人座位、电脑补位、开局座位稳定与洗牌发牌。
- 小横屏牌面命中区域至少 44×44，无页面横向溢出和目标牌/手牌重叠。
- 三个独立会话的完整对局：提牌、公开翻牌、成对/不成对、入手、配对、最后结算。

脚本清理自己创建的会话，不部署服务或修改生产配置。
