## 维护约定

1. **实际行为以源码和自动化测试为准**；文档若与实现不一致，应一并修正。
2. 游戏规则调整同步更新《游戏规则》《抽牌交互与界面》及规则测试。
3. 接口、存储、认证或部署调整同步更新相关工程文档。
4. 将“已经实现”“已自动化验证”和“尚未完成实机或公网验收”明确区分。
