# 手机版首页 · 2026-11-05

按用户提供的手机效果图与素材包调整 680 像素及以下的竖屏首页：木屋背景、派对乌龟标志、三只持牌乌龟、绿色牌背装饰、金色快速开始、绿色创建房间、奶油色加入房间，以及常显的简要规则。320 像素小屏允许纵向滚动，390×844 等较高屏幕可完整显示主要内容；桌面及横屏沿用既有首页布局。

## 素材

原图 `龟牌派对游戏UI素材包.png` 为 RGB，棋盘格属于图片内容，不是真实透明通道。使用内置 image_gen 清理外部棋盘格，清除按钮文字/图标及规则底板文字；保留标志、角色和装饰。背景从用户原图直接导出，其他部件从清理后的真实 RGBA 图层导出。

最终 12 张素材全部以带内容哈希的 WebP 保存于 `public/assets/mobile-home/`，合计 **183,974 字节**。无整张效果图或带固定按钮文案的截图被用作可操作界面。按钮文案、规则、按钮状态和可访问名称均保留为 HTML。

全部文件路径、尺寸、来源、生成工具及最终完整提示词见[手机版首页素材清单](手机版首页素材.json)。项目中不保存整张 PNG 图集；用户原图及 Codex 生成源图保留原位。

## 交互及加载

- 左上角为真实音效开关，与设置弹窗共用原有保存偏好；按钮有可访问名称、按下状态和 44 像素触控区域。
- 快速开始、创建和加入使用现有表单/API；没有建立第二套首页操作流程。
- `picture/source` 和条件预加载按视口选择背景与标志；等待或对局状态切换回原牌桌背景。
- 手机不请求旧首页的大规则插画和旧标志；桌面不请求这组手机素材。新 WebP 沿用一年不可变缓存。

## 验证

36 项原生测试通过。浏览器检查 320×568、360×640、390×844、430×932、768×1024、1440×900 和 844×390：无横向溢出、规则文字不裁切，图片正常解码；音效快捷开关、刷新持久化及其与设置的一致性通过，三个操作入口正常。

这是浏览器模拟视口验证，实体 Android/iPhone 触控与安全区域仍需实际设备验收。
