# 0.4 版：公开亮牌与同步选牌

## 使用变化

- 新建房间使用六位纯数字号码，保留前导零；加入表单使用数字键盘。
- 选择某张背面牌后，全桌对应牌位高亮，被抽者的那张手牌提起；可以改选或取消。只有确认抽取后才公开牌面。
- 每次抽牌都按“向全桌翻开 → 移入抽牌者手牌 → 配对消除或留牌”的顺序展示，包括最后一抽。未被抽出的其余手牌仍保密。
- 默认预留约 2.4 秒展示窗口，真人操作与电脑行动都遵守此窗口，下一回合的操作时限从展示后开始。
- 首页规则不再折叠；昵称、房间号与人数标签和对应输入控件同一行，主标题与操作按钮居中。
- 界面文案改为中文；牌面保留标准 A、J、Q、K 点数标记，内部牌组编码不变。

## 信息公平与兼容

所有观察者都能记住公开抽牌进入手牌末尾的位置。洗序、重排或无法追踪位置的公开配对会使相应的位置记忆失效；电脑没有读取未公开手牌或开局移除牌的权限。

旧版字母数字房间快照及会话仍能恢复，新建房间统一使用数字。选牌预览和展示锁属于短暂状态，进程恢复时清除，不会改变手牌或回合。重复动作仍按操作编号保持幂等。

## 验证

- 28 项 Node 原生自动化测试：覆盖数字房间号、前导零及旧快照、选牌权限与同步、公开牌面、展示期间操作保护、身份隔离、重复动作及进程恢复。
- 三个独立浏览器会话，通过真实表单创建和加入房间；视口为 1280×900、390×844、844×390。
- 一整局三人对局验证了未配对与配对抽牌、三方一致的亮牌、进入手牌后消除、最后一抽先动画再结算；验证局共抽牌 13 次，未出现页面异常。
- 已检查首页规则常显、界面中文、标签和输入框同一行及横向溢出。

模拟视口不等同于实体设备验收。实体手机触控、真实弱网切换及压力测试仍待完成。

## 沉浸式牌桌与 PNG 素材迭代

- 首页、等待与正式对局使用持久场景；二至六人围桌，开局不换桌、不重排玩家座位。
- 创建/加入、设置、牌桌内玩法和退出确认改为弹窗，支持退出键和焦点循环。
- 整包用户 PNG 原样解压至 public/assets，使用独立牌桌、头像、标志、装饰及无字底板，撤下此前 CSS 绘制的对应美术。动态内容仍由 HTML 渲染。
- 每张扑克牌保持独立 DOM，接入真实翻牌、入手及配对入弃牌区动画；原始整页参考图和示例文字不用于运行界面。
- 增加有界开局洗牌/发牌/初始配对反馈，以及默认开启的轻柔音效和减少动态效果偏好；转屏清理旧动画坐标。
- 补上六位数字加入校验、房间号碰撞验证，以及选牌者最后一条 SSE 断开时立即清除预览。

这版沉浸式视觉已于 2026-11-05 从开发分支先部署到腾讯云，公网三会话完整对局和浏览器回归通过；PR #2 仍待合并。实际提交、运行目录与回滚见[发布记录](../deploy/腾讯云发布-20261105.md)。实体手机、真实弱网、长期性能及压测仍待验收。

## 排版与牌面标记修正

弹窗与规则底板改用原始 PNG 的九宫格边框渲染，标题区固定且正文独立排布；按底图实际留白定位按钮文字。收敛多层冲突样式，统一控件、正文、标题和玩家信息的字号，并新增各类弹窗及六种视口的对齐断言。原始 PNG 未修改。

恢复标准 A、J、Q、K 标记：此前的一、侍等中文替换不是新牌种，已经移除。界面文案仍使用中文。原生测试增至 33 项。

## 等待座位、抽牌居中与默认音效

按钮改用去除内部椭圆高光线的 PNG 副本，原始素材保留。未入座的定位不再绘制框，玩家加入后才显示；玩家信息框禁止 flex 压缩，保持素材宽高比。抽牌区与目标牌列均水平居中。轻柔音效默认开启，用户手动关闭后保留选择，在用户点击或提交时激活音频。原生测试增至 35 项，并在浏览器验证空位、比例、居中与音效偏好。

## 参考图构图校准（2026-11-05）

替换放大的窗景条和独立牌桌，直接使用用户提供的无字完整房间底图；接入新透明图集中的徽标、木牌、等待标牌、主按钮及桌面装饰，补齐两名坐姿人物 PNG。桌面等待房间按参考坐标缩放，人物分列桌沿，房间号在上方、操作区在桌面下部。竖屏单独排布，人数较多时使用紧凑成员头像。

开局保留相同的玩家、身份和牌局，视角转为以手牌为中心的对局布局；并不保留等待人物与对局头像完全相同的屏幕坐标。房间号、玩家、按钮和每张牌仍使用真实 HTML/服务端状态，未把静态效果图作为可操作界面。新增跨视口的等待按钮和昵称裁切检查，并将持续 SSE 更新下的几何采样改为一次 DOM 读取，避免跨快照读到已被替换的节点。

## 加载速度与素材清理（2026-11-05）

公开目录清理未使用的参考图、预览、示例与元数据，实际图片转换为 42 张带内容哈希的透明 WebP；图片合计 708,418 字节。图集按实际使用部件拆分，背景提供两种分辨率并优先加载。不可变图片使用一年缓存，脚本与样式使用 ETag 重新验证，文本支持 gzip；HTML 和游戏接口不缓存。原素材可从 Git 历史及用户 ZIP 找回，详见[素材接入与优化](素材接入与优化.md)。新增真实 HTTP 回归，原生测试增至 36 项。
